# Gemini AI Clone

A simple web-based clone of Google Gemini AI, built with HTML, CSS, and JavaScript.

## Features

- Clean and modern UI inspired by Google Gemini
- Responsive design for desktop and mobile
- Interactive chat interface
- Easy to customize and extend

## Getting Started

1. **Clone the repository:**
   ```powershell
   git clone <your-repo-url>
   ```

2. **Navigate to the project folder:**
   ```powershell
   cd "Gemini"
   ```

3. **Open `index.html` in your browser to view the app.**

## Project Structure

```
Gemini/
├── index.html      # Main HTML file
├── script.js       # JavaScript logic
├── style.css       # Stylesheet
├── OG logo.png     # Project logo
├── LICENSE         # License file
└── README.md       # Project documentation
```

## Customization

- Update `style.css` to change the look and feel.
- Modify `script.js` to add new features or connect to an AI backend.
